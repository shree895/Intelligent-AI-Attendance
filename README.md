# Intelligent-AI-Attendance
# SnapClass

SnapClass is an AI-based smart attendance system designed to make attendance simple, fast, and efficient.

## Features

* **Face Recognition** – Takes attendance using facial recognition.
* **Voice Recognition** – Allows attendance through voice recognition.
* **QR Attendance** – Provides a shareable QR link for attendance.
* **Multiple Screens** – Includes separate screens for different users and activities.
* **Simple Interface** – Easy-to-use and user-friendly design.

## Technologies Used

* Python
* Streamlit
* Supabase
* Face Recognition
* Voice Recognition
* QR Code
